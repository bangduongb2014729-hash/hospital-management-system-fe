# Hospital Management System FE

Frontend Next.js App Router theo `Documents/plan-fe.md`.

## Chạy local

```bash
npm install
npm run dev
```

## Script

- `npm run dev`: chạy development server
- `npm run build`: build production
- `npm run lint`: kiểm tra ESLint
- `npm run test`: chạy Vitest

## Môi trường

Copy `.env.example` thành `.env.local` và cập nhật API URL khi backend sẵn sàng.
